# P1L0

Benchmark minimo 2D OpenSeesPy basado en la Pregunta 2 del Control 1.

## Contenido

- `docs/enunciado-control-1-p2.md`: resumen del ejercicio usado.
- `docs/explicacion.md`: explicacion del modelo y validacion.
- `docs/P1L0_explicacion_codigo.pdf`: PDF de explicacion del codigo.
- `docs/generar_pdf.py`: generador del PDF de explicacion.
- `opensees/ejemplo_minimo_2d.py`: script OpenSeesPy.
- `results/`: figuras generadas.
- `legacy/opensees/`: scripts historicos P1L0 conservados para trazabilidad; no son el script principal.

## Ejecutar

```powershell
python entregas/p1l0/opensees/ejemplo_minimo_2d.py
```
