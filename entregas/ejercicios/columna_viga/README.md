# Ejercicio Columna-Viga

Modelo 2D de una columna y viga de acero ASTM A36.

## Contenido

- `docs/explicacion.md`: hipotesis, resultados y verificacion.
- `opensees/columna_viga_2d.py`: script OpenSeesPy.
- `results/`: figuras generadas.

## Ejecutar

```powershell
python entregas/ejercicios/columna_viga/opensees/columna_viga_2d.py
```
