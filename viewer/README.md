# Viewer Unity

El único proyecto Unity activo está en `viewer/unity/`, con sus `.meta` originales.
Recibe datos generados desde modelo y resultados; no tiene fuentes estructurales
independientes. Abrir con `python main.py unity`, `Abrir_Unity.bat` o Unity Hub.
En Hub añadir `viewer/unity`, abrir `Assets/Main.unity` y pulsar Play.
La interfaz y el terreno no fueron alterados en la centralización de fuentes.
